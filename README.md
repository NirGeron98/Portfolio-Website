# Nir Geron Portfolio

Static React + Vite portfolio website for Nir Geron.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`

## Updating Content

Personal details, projects, skills, education, achievements, and experience are stored in `src/data/`.

Replace `public/Nir_Geron_Resume.pdf` with the current resume PDF when available.
